## 1. Comment tester la boutique immédiatement en local

Vous pouvez l'ouvrir directement dans votre navigateur :
* Double-cliquez simplement sur le fichier `index.html`
* OU ouvrez un terminal dans ce dossier et tapez :
  ```bash
  npm start
  ```
  Puis ouvrez `http://localhost:3000`

## 3. Comment configurer votre ID Partenaire Amazon

1. En haut à droite du site, cliquez sur **« Tag Partenaire »**.
2. Renseignez votre ID de suivi (ex : `matrouvaille-21`).
3. Cliquez sur **Enregistrer**.
👉 **Instantanément, tous les boutons « Voir l'offre sur Amazon » de tout le catalogue intègrent votre lien affilié !**

---

## 4. Comment mettre la boutique en ligne 100% GRATUITEMENT (2 minutes)

Pour donner l'adresse de votre site à Amazon lors de l'inscription :

### Option A : Déploiement ultra-rapide sur Netlify Drop (Sans ligne de commande)
1. Rendez-vous sur [app.netlify.com/drop](https://app.netlify.com/drop) (gratuit).
2. Glissez-déposez le dossier `curated-boutique` directement dans la fenêtre.
3. En 10 secondes, vous avez une adresse web sécurisée en `https://votre-boutique.netlify.app`.

### Option B : Déploiement Vercel
1. Installez Vercel via terminal : `npm i -g vercel`
2. Tapez `vercel` dans le dossier et validez avec Entrée.

---

## 5. Inscription au Club Partenaires Amazon

1. Allez sur [partenaires.amazon.fr](https://partenaires.amazon.fr).
2. Cliquez sur **« S'inscrire »**.
3. Renseignez vos informations et l'adresse de votre nouveau site.
4. Récupérez votre **Tracking ID** et collez-le dans le gestionnaire de votre boutique !
